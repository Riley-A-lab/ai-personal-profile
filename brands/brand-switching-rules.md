# 双品牌使用规则｜Brand Switching Rules

## 已确认原则
**KIWINURSE 与 Mosalogic 的产品型号相同；差异在品牌 Logo 与主题风格。**

## 生成前必须指定
- Brand: KIWINURSE / Mosalogic
- Product model: exact model code
- Asset type: product hero / application image / detail image / video / diagram
- Target market and audience
- Aspect ratio and publishing platform
- Reference assets: exact product image and correct brand reference

## 哪些内容共用
- 型号与产品基础结构
- 已核实的尺寸、功率、覆盖面积、配件和功能
- 产品安装方式、真实使用限制
- 产品结构保真和事实核实规则

## 哪些内容必须按品牌切换
- Logo 和 Logo 的具体呈现方式
- 品牌颜色、字体、排版和整体视觉主题
- Slogan、品牌文案和语气
- 品牌包装、品牌专属页面和活动设计

## 防错规则
1. 不要为两个品牌复制两套独立规格表；维护共用产品事实。
2. 不要在同一张图/视频中混用两个品牌 Logo 或 slogan，除非用户明确要求联名。
3. 如果产品照片上的 Logo 与目标品牌不一致，不要直接重绘产品并猜测 Logo。明确说明需要目标品牌的正确产品参考图，或只在用户明确要求时进行品牌替换。
4. 未确认的品牌风格不可自行假定为某种颜色、字体或“高端科技风”。
