# AI Personal Profile｜跨 AI 共享个人档案

> **用途：** 让不同 AI 助手了解我的背景、工作方式、沟通偏好、常用工具、项目经验、长期目标，以及我对 AI 产品图片/视频生成、品牌风格和产品资料的要求。
>
> **使用原则：** 本 README 是总入口。个人档案保留在首页；详细品牌规范、产品型号、生成口令和工作模板放在独立文件中，便于更新、复用和追溯。

## 1. 个人简介与背景｜Personal Introduction & Background

- **当前工作方向：** AI 辅助产品图片/视频制作、海外 B2B 营销素材与内容运营。
- **主要品牌/项目：** KIWINURSE、Mosalogic。
- **常见交付物：** 产品宣传视频、逐镜头分镜、AI 图片/视频生成口令、产品细节图、应用场景图、英文营销文案。
- **示例条目：** “我为海外 B2B 产品营销制作 AI 辅助的图片和视频内容，并持续整理可复用的提示词和产品资料。”
- **待补充：** 希望公开的教育/职业经历摘要、个人作品集链接。

## 2. 工作与学习习惯｜Work & Learning Habits

- 喜欢可执行、步骤清晰的说明；不熟悉的技术任务要拆成简单步骤。
- 偏好可复用的模板、检查清单、工作流程和标准化提示词。
- 工作方案要区分已确认事实、建议和待确认事项。
- 处理产品资料时，优先保证产品真实性，不为画面效果擅自改变产品。
- **示例条目：** “先确认品牌、型号、用途和参考图，再输出脚本、分镜、生成口令和发布文案。”

## 3. 沟通风格偏好｜Communication Style Preferences

- 默认用简洁、直接的中文沟通；面向海外市场时提供自然的英文文案。
- 生成口令要具体、可复制；过长时优先保留最关键的产品约束、画面要求和负面限制。
- 不要编造参数、功能、认证或性能效果。
- 产品参考图优先于文字猜测；信息不完整时标记“待确认”。
- **示例条目：** “严格使用上传产品图作为唯一产品外观参考，保持结构和比例不变，不增加未出现的零件。”

## 4. 常用工具与技术栈｜Tools & Technology Stack

- **ChatGPT：** 工作规划、文案、脚本、提示词和资料整理。
- **AI 图片/视频工具：** 产品图、场景图、视频画面和宣传内容制作。
- **飞书/Lark：** 工作计划、周报、表格与协作。
- **GitHub：** 保存跨 AI 共享档案、品牌规范、产品资料、提示词和版本记录。
- **示例条目：** “优先采用简单、可重复的工作流；涉及 GitHub 或编程时按新手步骤说明。”
- **安全提醒：** 不在公开仓库保存密码、API Key、客户隐私或公司机密。

- 提高 AI 产品视觉与视频生成质量，建立可复用的提示词体系。

## D. 如何让其他 AI 使用这些资料
1. 根据任务打开对应品牌规范和产品型号档案。
2. 将相关 Markdown 文件或内容上传/粘贴给目标 AI；仅发送仓库首页链接不保证对方会自动读取所有文件。
3. 生成前指定：品牌、型号、目标市场、内容类型、画幅、时长和参考图。
4. 生成后按检查清单核对产品结构、品牌元素、参数和文案。
