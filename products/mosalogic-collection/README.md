## 关于图片文件迁移
当前连接能检索到上述 Library 图片，但无法从该来源读取原始二进制文件来直接提交到 GitHub。因此，这一步先建立了资产清单和型号索引，**并未声称图片本身已经上传到 GitHub**。

若需要将图片也纳入 GitHub，请从原始「mosalogic产品合集」中下载/导出图片，再上传到仓库的 `assets/mosalogic/` 目录；建议按型号重命名，例如 `L08A-reference.png`，并避免把无法识别的图片直接当作官方产品图。

## 视觉参考原则
- 产品外观、结构和细节必须保持不变；不因场景生成而重设计产品。
- 场景应自然、真实、贴近日常使用；允许合理遮挡，但产品核心结构和 Logo 应清楚可辨。
- 产品合集已有分类时，后续整理应尽量保留原有分类。
- KIWINURSE 与 Mosalogic 使用相同产品型号和基础产品事实；根据目标任务替换正确的品牌 Logo 和主题风格。
- Mosalogic 的官方色值、字体和 slogan 尚需官方参考确认，不能仅凭产品合集图片推断成正式品牌规范。

## 每张图片建议补充的记录
- 图片文件名与产品型号
- 品牌 Logo 版本
- 产品类型/功能（有官方依据时填写）
- 尺寸/功率/光源/电源/覆盖面积（需核实）
- 外观锁定点
- 适用场景
- 对应生成口令或历史成片
- 数据来源与确认状态
