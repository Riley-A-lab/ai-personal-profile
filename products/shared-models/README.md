## 产品档案标准字段
每个型号文件建议包含：
- 官方型号名 / 别名
- 官方产品参考图（链接或仓库路径）
- 外观与结构锁定点
- 尺寸、功率、电源、光源、安装方式
- 覆盖面积、耗材/配件和使用限制
- 已确认功能与禁止宣称内容
- 可用场景和安装注意事项
- 数据来源、确认日期、待核实项
