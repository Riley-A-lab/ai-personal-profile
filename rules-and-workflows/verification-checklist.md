# 事实核实与发布前检查｜Verification Checklist

## A. 品牌核对
- [ ] 本次目标品牌明确：KIWINURSE 或 Mosalogic。
- [ ] Logo、品牌颜色、字体和 slogan 来自该品牌的正确参考资料。
- [ ] 没有混用另一品牌的视觉元素。

## B. 产品核对
- [ ] 型号与参考图一致。
- [ ] 外壳比例、开孔、灯管、端盖、Logo、材质和配件正确。
- [ ] 没有添加不存在的电击网格、导线或内部结构。
- [ ] 安装方式、场景尺度和使用环境合理。
- [ ] 型号参数来自已确认的官方规格，不是 AI 推断。

## C. 营销事实核对
- [ ] 覆盖面积、功率、尺寸、耗材和认证已核实。
- [ ] 未承诺未经证实的杀灭率、捕获率、绝对安全性或其他效果。
- [ ] 未将示意动画说成真实测试结果。
- [ ] 英文文案自然、准确，不夸大。

## D. 画面核对
- [ ] 产品完整清晰，没有被遮挡或变形。
- [ ] 飞虫大小、数量和运动自然。
- [ ] 光源效果克制真实，没有无依据的光束、烟雾或粒子。
- [ ] 画幅、构图、留白和发布平台要求符合 brief。
- [ ] 无错字、乱码、水印或未经要求的额外文字。

## E. 资料维护
- [ ] 新增事实标注来源和确认状态。
- [ ] 不确定的项目标记“待确认”。
- [ ] 不上传公司机密、客户隐私、密码或 API Key。
- [ ] 通过有意义的 Git commit 保存变更。
